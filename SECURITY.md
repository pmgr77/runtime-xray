# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in RuntimeXRay, please report it responsibly.

**Do not open a public GitHub issue.**  
Send an email to **[security@runtimexray.com](mailto:security@runtimexray.com)**.

We will acknowledge your report within 72 hours and provide a timeline for a fix.  
We kindly ask you to allow us a reasonable disclosure period before making any findings public.

## Supported Versions

Currently only the latest release receives security updates. A formal support matrix will be published as the project matures.

## Disclosure

We follow coordinated vulnerability disclosure. After a fix is released, we publish an advisory and credit the reporter (unless anonymity is requested).
