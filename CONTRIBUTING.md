# Contributing to RuntimeXRay

Thank you for your interest in contributing!

## Contributor License Agreement (CLA)

Before we can accept significant contributions, you must sign a Contributor License Agreement.  
The CLA is managed by **[cla-assistant.io](https://cla-assistant.io)**. When you open your first pull request, a bot will guide you through the signing process.

## How to contribute

1. Fork the repository.
2. Create a feature branch: `git checkout -b my-feature`.
3. Make your changes, add tests if applicable.
4. Ensure the existing test suite passes.
5. Commit with clear, descriptive messages.
6. Push to your fork and open a pull request against the `main` branch.

## Code style

- C++17 standard.
- Follow existing formatting (a `.clang-format` will be provided).
- Write meaningful comments and documentation.

## Reporting bugs

Open an issue with:
- Steps to reproduce
- Expected vs actual behavior
- RuntimeXRay version and environment details

For security‑sensitive bugs, do **not** open a public issue – see `SECURITY.md`.
